# Screenshot evidence

Add genuine screenshots captured from the running project to this folder. Suggested filenames and required context are listed in [the Mokxi simulation guide](../docs/mokxi-simulation.md). Do not add mockups as test evidence. Recommended images: `mokxi-circuit.png`, `mokxi-serial-normal.png`, `mokxi-serial-fault.png`, `dashboard-normal.png`, `dashboard-fault.png`, and `digital-twin.png` (only if that view is implemented in the checked-out frontend).
